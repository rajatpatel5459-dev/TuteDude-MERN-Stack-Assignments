# Task 1: (Hello World) HTML

This is a beginner-level HTML project that displays a **Hello World** message in the browser.

## Project Description

When you open the `index.html` file in a browser, it displays a **Hello World** heading on the page.

## Technology Stack

- HTML5

## What I Learned

- How to create the basic structure of an HTML document
- How to use `<!DOCTYPE html>`
- How to use the `<html>`, `<head>`, and `<body>` tags
- How to display a main heading using the `<h1>` tag
- How to open an HTML file in a browser

## How to Run

1. Open the `Task_1` folder.
2. Double-click the `index.html` file, or open it in any web browser.
3. The **Hello World** message will appear on the screen.
